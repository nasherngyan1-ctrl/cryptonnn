# OKX Kurd AI Pro (ئۆکەی ئێکس کورد AI پرۆ)

ئەپلیکەیشنێکی پڕۆفیشناڵی ئەندرۆید بە زمانی کوردی (سۆرانی) و شێوازی ڕاست-بۆ-چەپ (**RTL**)، کە ڕاستەوخۆ بەستراوەتەوە بە داتای زیندووی بازاڕی **OKX API v5** و سیستەمی زیرەکی دەستکردی **Gemini 3.8 Flash (Firebase AI Logic)**.

---

## تایبەتمەندییە سەرەکییەکان

1. **خشتەی زانیارییە زیندووەکانی بازاڕی OKX (Spot & Perpetual Swap)**:
   - نرخی چرکەبەچرکەی دراوەکان بە وردی تا ٨ ژمارەی دوای فاریزە.
   - بەرزترین و نزمترین نرخی ٢٤ کاتژمێر، قەبارە بە USDT، ڕێژەی ناجێگیری، و باشترین نرخی کڕین و فرۆشتن (`Best Bid / Best Ask / Spread bps`).
2. **پێشبینیکەری قووڵی زیرەکی دەستکرد (Gemini 3.8 Flash)**:
   - شیکردنەوەی ماتماتیکی هەر ٤ تایمفرەیمەکە (`15m`, `1H`, `4H`, `1D`) لەگەڵ ٥٠ ئاستی Order Book و ڕێژەی Funding Rate.
   - دیاریکردنی خاڵی وردی چوونەژوورەوە (`Entry Zone`)، ٣ ئامانجی قازانج (`TP1`, `TP2`, `TP3`)، وەستانی زیان (`Stop-Loss`)، و پێشبینی نرخی ١ کاتژمێر، ٤ کاتژمێر، و ٢٤ کاتژمێری داهاتوو.
3. **شیکاری زیرەکی وێنەی کڕین («لە چەند بیفرۆشم قازانجمە؟»)**:
   - وێنەی کڕینی کۆینەکەت یان مامەڵەکەت بنێرە؛ زیرەکی دەستکرد کۆینەکە و نرخی کڕینەکەت دەخوێنێتەوە، بەراوردی دەکات لەگەڵ دیوارەکانی فرۆشتنی نەهەنگەکان لە OKX، و پێت دەڵێت لە چ نرخێکدا بیفرۆشیت بۆ زۆرترین قازانج (`Golden Exit Price` + `TP1/TP2/TP3`).
4. **بژمێری فیوچەرز و چاودێری سیگناڵەکان**:
   - پاشەکەوتکردنی سیگناڵەکانی AI لەسەر ئامێرەکەت (`Room Database`) و بەراوردکردنی زیندوویان لەگەڵ نرخی ئێستای بازاڕ، لەگەڵ بژمێری قەبارەی گرێبەست و نرخی لیکویدەیشن.

## چۆنیەتی وەرگرتنی فایلی APK و ناردنی بۆ GitHub

### ڕێگەی یەکەم: ڕاستەوخۆ لەناو AI Studio
- لە بەشی سەرەوەی شاشەی AI Studio کرتە لە **Settings (⚙️)** بکە:
  - بۆ وەرگرتنی فایلی APK: کرتە لە **Generate APK** بکە بۆ دابەزاندنی ڕاستەوخۆی فایلەکە بۆ ناو مۆبایلەکەت.
  - بۆ ناردن بۆ GitHub: کرتە لە **Export to GitHub / Push to GitHub** بکە.

### ڕێگەی دووەم: دروستکردنی خۆکاری APK لە ڕێگەی GitHub Actions
ئەم پڕۆژەیە فایلی فەرمی وۆرکفلۆی گیتهەبی تێدایە لە شوێنی:
`.github/workflows/build-apk.yml`

هەر کاتێک کۆدەکە دەنێریت بۆ **GitHub**:
1. بە شێوەی خۆکار لە بەشی **Actions** فایلی دامەزراندنی **`OKX-Kurd-AI-Pro.apk`** دروست دەکرێت و واژۆ دەکرێت بە هەمان کلیلی فەرمی Firebase.
2. هەروەها لە بەشی **Releases**ی گیتهەبەکەت وەشانێکی نوێ دادەنرێت کە دەتوانیت ڕاستەوخۆ فایلی `OKX-Kurd-AI-Pro.apk`ـی لێ دابەزێنیت و لەسەر مۆبایلەکەت دایبمەزرێنیت.
